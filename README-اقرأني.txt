ROYA — طريقة التشغيل على الموبايل
1) ارفع محتويات المجلد (كل الملفات) على أي استضافة HTTPS مجانية، مثلا:
   - Netlify Drop: app.netlify.com/drop  (اسحب المجلد وخلاص)
   - أو GitHub Pages / Cloudflare Pages
   (لازم HTTPS علشان الكاميرا والتثبيت يشتغلوا)
2) افتح الرابط من Chrome على الموبايل ← القائمة ⋮ ← "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية".
3) أول مرة افتحه وإنت متصل بالإنترنت (لتحميل خط Cairo)، وبعدها بيشتغل حتى بدون نت.
ملاحظة: البيانات محفوظة على نفس الموبايل — استخدم زر "حفظ نسخة" في الإعدادات (⚙) بشكل دوري.
